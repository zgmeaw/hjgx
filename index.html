🔧 管理博主链接

使用说明：
1. 点击"添加链接"按钮添加新链接
2. 填写博主名称和链接地址
3. 新添加的链接名称可以为空，等下一次自动执行爬取任务时会自动补上
4. 点击"删除"按钮删除链接
5. 首次使用需要输入 GitHub Token，之后会自动保存到浏览器中
6. 点击"保存"按钮保存链接

💡 提示：链接和名称会保存到 links.txt 文件（加密存储）。Token 仅存储在您的浏览器中，不会上传到服务器。
💡 Token 仅存储在您的浏览器中，不会上传到服务器。创建 Token 时需勾选 "repo" 权限。
